GOSPEL LMS - LOCAL DEMO ON WINDOWS
==================================
You need ONLY two things installed (no Composer, no Node.js, nothing else):

 1. PHP 8.3 or newer (x64, "Thread Safe" zip) from https://windows.php.net/download/
      - unzip to C:\php
      - add C:\php to your PATH (Start > "Edit the system environment variables" > Environment Variables > Path > New > C:\php)
      - close and reopen PowerShell, then check:  php -v
 2. PostgreSQL 16 from https://www.postgresql.org/download/windows/  (accept the defaults; write down the password you set for "postgres")

Then:

 A. Unzip gospel-lms-demo.zip, for example to C:\global-lms  (so that C:\global-lms\backend exists).
 B. Open PowerShell in that folder and run ONCE:
        powershell -ExecutionPolicy Bypass -File setup-demo.ps1
    (it switches on the PHP extensions, creates the database, loads the demo data. Enter the postgres password when asked.)
 C. Double-click  start-demo.bat   -> your browser opens http://127.0.0.1:8000
    Keep the black window open while presenting. Close it to stop.

COURSES IN THE DEMO
    "[DEMO] Introduction to the Gospels"  - free, 2 lessons (unlock in order) + a quiz
    "E2E Paid Course" - N25,000, ends with a FINAL EXAM. Paying uses a built-in DEMO payment page (it is NOT Paystack
                        and moves no money; it is a small PHP script started by start-demo.bat).
    Full journey to show: register -> verify email -> pay -> lesson -> final exam -> certificate -> public verification (/verify).

EMAIL: nothing is really sent. To verify a new student's email, open  backend\storage\logs\laravel.log  and copy the last
       link that contains "verify-email" into the browser (or sign in as admin > Users). The prepared student accounts are already verified.

CERTIFICATE TEMPLATE: sign in as admin > Certificates > "Template & layout" > upload your artwork (sample: certificate-template-sample.png).

IF SOMETHING GOES WRONG
    "Missing php extension"  -> open php.ini (path shown by:  php --ini ), remove the ';' before extension=pdo_pgsql and extension=pgsql, extension=mbstring, extension=intl, extension=zip, extension=gd, extension=fileinfo
    Port 8000 busy           -> close other programs or edit the 8000 numbers in start-demo.bat and in backend\.env (APP_URL, SANCTUM_STATEFUL_DOMAINS)
    Blank page / API errors  -> look at backend\storage\logs\laravel.log
    Start again from scratch -> run setup-demo.ps1 again (it resets the demo data)
This is a demonstration setup (local data, fake payment page, emails not sent). It is not a production installation.
